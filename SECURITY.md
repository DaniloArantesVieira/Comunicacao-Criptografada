# Política de Segurança

## Escopo

Este repositório é um projeto educacional e laboratorial voltado ao estudo de
comunicação segura, criptografia aplicada, certificados digitais e redes privadas.

O projeto não deve ser considerado, sem revisão adicional, uma implementação
pronta para ambientes de produção.

## Segredos e material criptográfico

Chaves privadas, certificados gerados, credenciais, arquivos .env e outros
segredos não devem ser versionados no repositório.

Caso uma chave privada ou credencial seja exposta publicamente, ela deve ser
considerada comprometida e substituída.

## Relato de vulnerabilidades

Caso seja identificada uma vulnerabilidade de segurança, evite publicar
informações sensíveis, credenciais ou material criptográfico real em issues
públicas.

## Uso responsável

Os componentes deste projeto devem ser utilizados somente em ambientes
autorizados, controlados e destinados a estudo, teste ou desenvolvimento.
